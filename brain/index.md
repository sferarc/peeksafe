# Brain

Knowledge vault for peeksafe, readable as an Obsidian vault. One topic per file, wikilinks for cross-references. It records how the library works and why it is shaped the way it is, with a source path for every claim so a reader can check it. Where something is not known, the note says so.

The README is the user documentation and stays the authority on the public API. These notes are for someone changing the code.
